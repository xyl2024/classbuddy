# 题型与数据结构说明

本文档总结当前系统支持的题型、试卷（数据）目录结构以及各类题型的数据结构。领域术语见 `CONTEXT.md`：考试集 → 试题组 → 材料 / 题目集合 → 题目。

## 一、支持的题型总览

| 题型 | `type` 字段值 | 布局 | 交互方式 |
| --- | --- | --- | --- |
| 情景交际（对话补全） | `dialogue-choice` | 单栏（无材料区） | 选错标红并展示解析，选对视为预览答案 |
| 阅读理解 | `choice`（可省略） | 材料区 + 题目区（2:1） | 同上 |
| 五选五（选句填空） | `gap-fill` | 短文内嵌题目区 | 逐空预览答案与解析 |
| 完形填空 | `cloze` | 短文内嵌题目区 | 同单选题（选错标红展示解析，选对预览答案） |
| 语法填空 | `grammar-fill` | 短文内嵌题目区 | 纯预览式（无可点击选项），空槽显示提示词、预览后填充答案 |
| 书面表达 | `writing` | 单栏（无材料区） | 预览后作文纸展示范文与点评 |

通用约定：

- 答案默认隐藏，可逐题或全部预览；预览时显示正确答案和解析。
- 题目区域用于教师讲解，不是学生答题系统；不涉及答题提交、判分或用户系统。
- 带 `{{blank:题号}}` 标记的短文内嵌在题目区展示，不写入 `material.md`（避免影响批注偏移量）。

## 二、试卷目录结构

启动参数 `--data` 指向包含多个考试集的根目录：

```text
<data-dir>/
└── examination-name/             # 考试集（顶层目录）
    ├── meta.json                 # 可选，考试集元数据（name、description）
    └── item-1/                   # 试题组（共享同一份材料的一组题目）
        ├── meta.json             # 试题组元数据（name，可选 sectionType、instruction、scorePerQuestion、totalScore、description、score）
        ├── material.md           # 材料（Markdown，支持标题、段落、列表、粗体、斜体、引用）
        ├── questions.json        # 题目数组
        └── annotations.json      # 批注，不存在时可由服务创建
```

`meta.json` 字段说明：

```json
{
  "name": "阅读理解",
  "sectionType": "reading-comprehension",
  "instruction": "阅读下列短文，掌握其大意，然后从每题所给的 A、B、C 和 D 项中选出最佳选项。",
  "scorePerQuestion": 3,
  "totalScore": 15,
  "description": "共5小题"
}
```

- `name`：试题组名称，**必须是且只能是** `情景交际`、`阅读理解`、`五选五`、`完形填空`、`语法填空`、`书面表达` 六者之一；该名称直接用作材料卡片与题目卡片的标题，不能带篇目、副标题或附加文字（篇目区分写在材料正文首行标题或 `description` 中）。
- `sectionType`：题型标记，可选值 `situational-communication`、`reading-comprehension`、`gap-fill`、`cloze`、`grammar-fill`、`writing`。
- `instruction`：该大题的题干说明文字。
- `scorePerQuestion` / `totalScore`：每题分值 / 总分（部分旧数据使用整组 `score`）。
- `description`：备注描述。

单个试题组文件异常不应导致整个服务启动失败，会在导航中标记异常。

## 三、各题型数据结构

以下结构定义在 `src/types.ts`，`questions.json` 中的每个元素对应一种题型。

### 1. 情景交际（对话补全，`dialogue-choice`）

短对话补全题，采用单栏布局。每道题自带一段对话，对话中待填位置用 `{{blank}}` 标记，从选项中选出最佳应答。

```json
{
  "id": "q1",
  "type": "dialogue-choice",
  "dialogue": [
    { "speaker": "Mike", "text": "Mike, thank you for driving me home." },
    { "speaker": "You", "text": "{{blank}} Have a nice day." }
  ],
  "options": [
    { "key": "A", "text": "That's right" },
    { "key": "B", "text": "I'm afraid not" },
    { "key": "C", "text": "You're welcome" },
    { "key": "D", "text": "That's a good idea" }
  ],
  "answer": "C",
  "explanation": "对方表示感谢时，应回答“You're welcome”。"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `dialogue` | `{speaker, text}[]` | 对话行，说话人 + 台词；`{{blank}}` 为待填空位 |
| `options` | `{key, text}[]` | 备选项 |
| `answer` | `string` | 正确选项 key |
| `explanation` | `string?` | 解析（预览时显示） |

### 2. 阅读理解（`choice`）

普通单选题，材料写在 `material.md`，题目按顺序展示题干 + 四个选项。交互：选错标红并展示解析，选对视为预览答案。

```json
{
  "id": "q1",
  "type": "choice",
  "question": "What can we learn about the writer from Paragraph 1?",
  "options": [
    { "key": "A", "text": "……" },
    { "key": "B", "text": "……" },
    { "key": "C", "text": "……" },
    { "key": "D", "text": "……" }
  ],
  "answer": "B",
  "explanation": "解析文字"
}
```

`type` 字段可省略（缺省即 `choice`），这是最基础的兼容题型。

### 3. 五选五 / 选句填空（`gap-fill`）

高考“七选五”类题型（五选五为其空数为 5 的形式）：整篇短文 + 整组共用备选句子，可含干扰项（如 5 空 7 选项）。短文内空位用 `{{blank:题号}}` 标记，逐空预览答案与解析。

```json
{
  "id": "gf1",
  "type": "gap-fill",
  "passage": "Plant-based ice creams have become a good summer choice these days. {{blank:16}} If you doubt it, ……",
  "options": [
    { "key": "A", "text": "And there are several reasons for it." },
    { "key": "B", "text": "……" }
  ],
  "blanks": [
    { "label": "16", "answer": "B", "explanation": "解析文字" }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `passage` | `string` | 短文原文，空位用 `{{blank:题号}}` 标记；`\n` 表示段落分隔 |
| `options` | `{key, text}[]` | 备选句子（整组共用，可含干扰项） |
| `blanks` | `{label, answer, explanation?}[]` | 逐空答案：`label` 为与试卷一致的题号，`answer` 为正确选项 key |

### 4. 完形填空（`cloze`）

整篇短文 + 逐空独立的 A/B/C/D 四个选项；空位同样用 `{{blank:题号}}` 标记。交互与单选题一致。

```json
{
  "id": "cl1",
  "type": "cloze",
  "passage": "Kate was a shy girl. One day her teacher asked her to {{blank:21}} ……",
  "blanks": [
    {
      "label": "21",
      "options": [
        { "key": "A", "text": "jump" },
        { "key": "B", "text": "smile" },
        { "key": "C", "text": "leave" },
        { "key": "D", "text": "cry" }
      ],
      "answer": "B",
      "explanation": "解析文字"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `passage` | `string` | 短文原文，空位用 `{{blank:题号}}` 标记 |
| `blanks` | `{label, options, answer, explanation?}[]` | 每空独立的四个备选项 + 正确选项 key + 解析 |

### 5. 语法填空（`grammar-fill`）

整篇短文 + 逐空填词：每空填一个单词或括号内单词的正确形式。`hint` 为可选括号提示词（无提示词的纯填空省略）。空槽内显示提示词，预览后填充答案单词；交互为纯预览式，无可点击选项。

```json
{
  "id": "gr1",
  "type": "grammar-fill",
  "passage": "Mr. Grey loved collecting things. He had a large {{blank:36}} of old stamps. {{blank:37}} he was young, ……",
  "blanks": [
    { "label": "36", "hint": "collect", "answer": "collection", "explanation": "……" },
    { "label": "37", "answer": "When", "explanation": "……" }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `passage` | `string` | 短文原文，空位用 `{{blank:题号}}` 标记 |
| `blanks` | `{label, hint?, answer, explanation?}[]` | `hint` 为括号提示词（可省略），`answer` 为单词或词形（非选项） |

### 6. 书面表达（`writing`）

写作题，采用单栏布局（无材料区），预览后以作文纸形式展示范文与点评。

```json
{
  "id": "writing1",
  "type": "writing",
  "prompt": "假定你是李华。你的外国朋友 Peter 计划寒假来中国旅游……",
  "greeting": "Dear Peter,",
  "closing": "Yours,\nLi Hua",
  "points": ["表示欢迎", "介绍游玩安排：品尝美食、参观博物馆、参加朋友聚会等", "期待他的到来"],
  "sample": "I'm more than happy to hear that you're coming to China……",
  "comment": "范文点评文字"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `prompt` | `string` | 题干与写作要求 |
| `greeting` | `string?` | 已给出的开头（如 `Dear Peter,`） |
| `closing` | `string?` | 已给出的结尾（如 `Yours,\nLi Hua`） |
| `points` | `string[]?` | 写作要点 |
| `sample` | `string?` | 参考范文（预览后展示） |
| `comment` | `string?` | 范文点评 |

## 四、批注数据结构（annotations.json）

批注附着于试题组，包括文本高亮、划线（基于文本偏移量）、自由笔迹和直线（基于画布坐标点）；文本批注可附带笔记。每次操作后自动保存到当前试题组的 `annotations.json`。

```json
{
  "version": 1,
  "annotations": [
    {
      "id": "a1",
      "type": "highlight",
      "target": "material",
      "start": 12,
      "end": 40,
      "note": "重点句型"
    },
    {
      "id": "a2",
      "type": "freehand",
      "target": "questions",
      "points": [[10, 20], [50, 80]],
      "color": "#ff0000",
      "width": 3
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `type` | `highlight`（高亮）/ `underline`（划线）/ `freehand`（自由笔迹）/ `line`（直线） |
| `target` | 所属面板：`material`（材料区）/ `questions`（题目区），缺省视为材料区（兼容旧数据） |
| `start` / `end` / `text` | 文本批注（highlight/underline）：相对对应面板全文的字符偏移区间 |
| `points` | 笔迹批注（freehand/line）：相对对应面板画布的坐标点序列 |
| `note` | 文本批注附带的笔记 |
| `color` / `width` | 笔迹批注的画笔颜色与粗细 |

## 五、接口返回结构（GET /api/items/:exam/:item）

```json
{
  "meta": { "name": "……", "sectionType": "……", "instruction": "……", "scorePerQuestion": 3, "totalScore": 15 },
  "material": "Markdown 原文",
  "questions": [ /* 上述各题型对象组成的数组 */ ],
  "annotations": { "version": 1, "annotations": [] }
}
```
